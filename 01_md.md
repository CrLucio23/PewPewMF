# STEP 1: Setup Progetto, PostgreSQL, Modello Dati (`@Entity`) e Repository

> **Prerequisito:** Leggi `00_MASTER_RULES.md`.
> **Obiettivo Commit 1:** Creare la struttura base Spring Boot 3, configurare la connessione a PostgreSQL e implementare l'intero Data Tier (Entity, Enum e Repository) del dominio PEWPEW MF.
> **NON generare:** Controller, Service, Security o file HTML/CSS in questo step.

---

## Task 1.1: Configurazione `pom.xml` e `application.properties`
1. Verifica/configura `pom.xml` con Java 21 e le seguenti dipendenze Spring Boot:
   - `spring-boot-starter-web` (con Tomcat embedded)
   - `spring-boot-starter-thymeleaf`
   - `spring-boot-starter-data-jpa`
   - `spring-boot-starter-security`
   - `thymeleaf-extras-springsecurity6`
   - `spring-boot-starter-validation`
   - `org.postgresql:postgresql` (runtime)
   - `org.projectlombok:lombok` (opzionale, se usato mantenere coerenza)
2. Configura `src/main/resources/application.properties`:
   - `spring.application.name=pewpew-mf`
   - `spring.datasource.url=jdbc:postgresql://localhost:5432/pewpewmf_db`
   - `spring.datasource.username=postgres`
   - `spring.datasource.password=postgres`
   - `spring.jpa.hibernate.ddl-auto=update`
   - `spring.jpa.show-sql=true`
   - `spring.jpa.properties.hibernate.dialect=org.hibernate.dialect.PostgreSQLDialect`

## Task 1.3: Entità JPA (`it.pewpewmf.platform.model`)
Implementa le seguenti `@Entity` con vincoli JPA (`@NotNull`, `@Column`, relazioni `@ManyToOne`, `@OneToMany`, `@ManyToMany`):

1. **`Utente`**:
   - `id` (Long, PK, Identity)
   - `nome` (String)
   - `cognome` (String)
   - `username` (String, unique, not null)
   - `email` (String, unique, not null)
   - `password` (String, not null)
   - `ruolo` (`@Enumerated(EnumType.STRING)` `RuoloUtente`)
   - `dataRegistrazione` (LocalDateTime)

2. **`Partner`**:
   - `id` (Long, PK, Identity)
   - `nome` (String, not null)
   - `descrizione` (String, columnDefinition = "TEXT")
   - `logoUrl` (String)
   - `sitoWeb` (String)
   - `categoriaPartner` (String — es. "Produttore Repliche", "Campo Tattico", "Sponsor Ufficiale")

3. **`Attrezzatura`**:
   - `id` (Long, PK, Identity)
   - `nome` (String, not null)
   - `codiceSku` (String, unique, not null)
   - `descrizione` (String, columnDefinition = "TEXT")
   - `prezzoAcquisto` (BigDecimal, not null)
   - `prezzoNoleggioSessione` (BigDecimal, not null)
   - `disponibilitaVendita` (Integer, not null)
   - `disponibilitaNoleggio` (Integer, not null)
   - `zonaCorpo` (`@Enumerated(EnumType.STRING)` `ZonaCorpo`, not null)
   - `categoria` (String — es. "Caschi & Maschere", "Plate Carrier", "ASG Fucili", "Anfibi & Pantaloni")
   - `immagineUrl` (String)
   - `partner` (`@ManyToOne` verso `Partner`)

4. **`Evento`**:
   - `id` (Long, PK, Identity)
   - `titolo` (String, not null)
   - `descrizione` (String, columnDefinition = "TEXT")
   - `luogo` (String, not null)
   - `dataInizio` (LocalDateTime, not null)
   - `dataFine` (LocalDateTime, not null)
   - `immagineUrl` (String)
   - `partners` (`@ManyToMany` verso `Partner`, tabella ponte `evento_partner`)

5. **`SessioneGioco`**:
   - `id` (Long, PK, Identity)
   - `titolo` (String, not null — es. "Urban CQB Notturno", "Dominazione Boschiva")
   - `descrizione` (String, columnDefinition = "TEXT")
   - `campo` (String, not null)
   - `dataOraInizio` (LocalDateTime, not null)
   - `durataOre` (Integer, not null)
   - `prezzoBaseSessione` (BigDecimal, not null)
   - `postiTotali` (Integer, not null)
   - `postiDisponibili` (Integer, not null)
   - `eventoAssociato` (`@ManyToOne` nullable verso `Evento`)

6. **`Prenotazione`**:
   - `id` (Long, PK, Identity)
   - `codicePrenotazione` (String, unique, not null)
   - `utente` (`@ManyToOne`, not null)
   - `sessioneGioco` (`@ManyToOne`, not null)
   - `conNoleggioAttrezzatura` (Boolean, not null)
   - `attrezzatureNoleggiate` (`@ManyToMany` verso `Attrezzatura`, tabella ponte `prenotazione_noleggio_attrezzatura`)
   - `totalePagato` (BigDecimal, not null)
   - `stato` (`@Enumerated(EnumType.STRING)` `StatoPrenotazione`)
   - `dataCreazione` (LocalDateTime)

7. **`Ordine`** e **`DettaglioOrdine`**:
   - `Ordine`: `id`, `codiceOrdine` (unique), `utente` (`@ManyToOne`), `dataOrdine` (LocalDateTime), `totale` (BigDecimal), `statoOrdine` (String), `dettagli` (`@OneToMany(cascade = CascadeType.ALL)`).
   - `DettaglioOrdine`: `id`, `ordine` (`@ManyToOne`), `attrezzatura` (`@ManyToOne`), `quantita` (Integer), `prezzoUnitario` (BigDecimal).

8. **`TicketSupporto`** e **`MessaggioTicket`**:
   - `TicketSupporto`: `id`, `codiceTicket` (unique), `utente` (`@ManyToOne`), `oggetto` (String), `categoria` (String — es. "Supporto Tecnico Attrezzatura", "Prenotazioni", "Ordini"), `priorita` (`PrioritaTicket`), `stato` (`StatoTicket`), `dataApertura` (LocalDateTime), `ultimoAggiornamento` (LocalDateTime), `messaggi` (`@OneToMany(cascade = CascadeType.ALL)`).
   - `MessaggioTicket`: `id`, `ticket` (`@ManyToOne`), `autore` (`@ManyToOne` `Utente`), `testo` (String, columnDefinition = "TEXT"), `dataInvio` (LocalDateTime), `rispostaStaff` (Boolean).

## Task 1.4: Repository (`it.pewpewmf.platform.repository`)
Crea le interfacce estendendo `JpaRepository`:
- `UtenteRepository` (con `findByUsername`, `findByEmail`, `existsByUsername`, `existsByEmail`)
- `PartnerRepository`
- `AttrezzaturaRepository` (con `findByZonaCorpo`, `findByPartnerId`, `findByCategoriaContainingIgnoreCase`, e query per articoli disponibili al noleggio `findByDisponibilitaNoleggioGreaterThan(0)`)
- `EventoRepository` (con `findByPartnersId`)
- `SessioneGiocoRepository` (con `findByDataOraInizioAfterOrderByDataOraInizioAsc`)
- `PrenotazioneRepository` (con `findByUtenteIdOrderByDataCreazioneDesc`)
- `OrdineRepository` (con `findByUtenteIdOrderByDataOrdineDesc`)
- `TicketSupportoRepository` (con `findByUtenteIdOrderByUltimoAggiornamentoDesc`, `findAllByOrderByUltimoAggiornamentoDesc`)
