# STEP 6: Login/Registrazione, Carrello Acquisti, Area Account e Supporto Tecnico Sempre Operativo

> **Prerequisito:** Leggi `00_MASTER_RULES.md`. Lo Step 5 deve essere completato.
> **Obiettivo Commit 6:** Completare il sistema con autenticazione utente, carrello e-commerce per l'acquisto dell'attrezzatura, dashboard Account personale e modulo di Supporto Tecnico sempre operativo tramite Ticket.

---

## Task 6.1: Controller Autenticazione, Carrello, Account e Ticket
Crea nel package `it.pewpewmf.platform.controller`:

1. **`AuthController`**:
   - `@GetMapping("/login")` -> `login.html`
   - `@GetMapping("/registrazione")` e `@PostMapping("/registrazione")` -> `registrazione.html` (con validazione e messaggio di conferma).

2. **`CarrelloController`** (gestito tramite `@SessionAttributes` o `HttpSession`):
   - `@GetMapping("/carrello")` -> `carrello.html`
   - `@PostMapping("/carrello/aggiungi")` -> aggiunge articolo + quantità e torna alla pagina precedente o al carrello.
   - `@PostMapping("/carrello/rimuovi")` -> rimuove articolo.
   - `@PostMapping("/carrello/checkout")` -> crea `Ordine` tramite `OrdineService`, svuota il carrello e reindirizza a `/account?ordineSuccess`.

3. **`AccountController`**:
   - `@GetMapping("/account")` -> `account.html`: dashboard completa dell'operatore autenticato con:
     - Dati profilo utente.
     - Tab **I Miei Ordini** (storico acquisti attrezzatura).
     - Tab **Le Mie Prenotazioni** (sessioni prenotate con dettaglio se con o senza noleggio e tasto annulla).
     - Tab **I Miei Ticket di Supporto** + pulsante rapido **"Apri Nuovo Ticket"**.

4. **`TicketSupportoController`**:
   - `@GetMapping("/ticket")` -> se l'utente ha ruolo `SUPPORTO` o `ADMIN` mostra la console di gestione di **tutti** i ticket aperti; se è `CLIENTE` mostra i propri ticket e il form rapido per aprirne uno nuovo (`ticket-lista.html`).
   - `@PostMapping("/ticket/nuovo")` -> crea nuovo ticket (`StatoTicket.APERTO`) con primo messaggio.
   - `@GetMapping("/ticket/{id}")` -> vista chat/thread del singolo ticket (`ticket-dettaglio.html`).
   - `@PostMapping("/ticket/{id}/rispondi")` -> aggiunge un messaggio al thread (impostando `rispostaStaff = true` se l'autore ha ruolo `SUPPORTO`/`ADMIN`).
   - `@PostMapping("/ticket/{id}/stato")` -> permette allo staff di supporto di aggiornare lo stato (`IN_LAVORAZIONE`, `RISOLTO`, `CHIUSO`).
